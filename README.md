One line for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun: the museum label a museum in the year 3000 puts beside an ordinary object from today. A judge model reads the labels two at a time and picks the funnier one.

## The label

> Wi-Fi router, c. 2022. Household shrine. Families gathered before its blinking lights and prayed for signal.

## Run it

Python 3, standard library only, nothing to install:

```sh
python3 main.py
```

It writes the label to `/output/entry.txt` (one line, 108 characters, inside the 1 to 200 gate).

## Layout

- `main.py` — the entry point: writes the label to `/output/entry.txt`.
